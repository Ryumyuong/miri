## 데이터 의미와 미확인

- 홈페이지와 관리자 등록은 같은 reservations 명부에 들어간다. 출처 필드가 없어 이를 임의로 구분하지 않고 “명부”로 표시한다.
- offlineHold는 사람별 ID 없는 추가 숫자다. 동일인을 명부로 옮길 때 이 숫자를 직접 차감해야 하며 도움말에 명시했다. 이름 추측으로 자동 병합하지 않는다.
- 여권은 사람, 목록의 계약금은 기존 팀 집계이므로 표시 단위를 팀으로 바로잡았다.
- 신규예약 월별 수치는 생성일 있는 명부만 사용한다. 오프라인 숫자에는 생성일/개인정보가 없으므로 월별 신규 명부예약에서 제외라고 명시했다.
- 현재 서버 실행 중 화면에서 새 버전 확인은 사용자 배포 후 필요하다. 이번 후속 수정은 DB 마이그레이션/데이터 변경이 필요 없다. 운영 DB 규칙은 미확인 상태이며 변경하지 않았다.
